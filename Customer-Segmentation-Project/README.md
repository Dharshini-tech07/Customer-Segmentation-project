# Customer Segmentation Project

## Objective
Analyze customer purchasing behavior using K-Means Clustering.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Dataset
Sample_Superstore.xls

## Features
- Data preprocessing
- Customer segmentation using K-Means
- Visualization of customer clusters
- Cluster center identification

## Output
The project groups customers into different segments based on Sales and Profit and visualizes the clusters using a scatter plot.

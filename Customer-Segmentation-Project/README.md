# Customer Segmentation Project

## 📌 Project Overview
This project performs customer segmentation using the K-Means Clustering algorithm. It analyzes customer purchase data based on **Sales** and **Profit** to group customers with similar purchasing behavior. The results are visualized using a scatter plot to help understand different customer segments.

## 🎯 Objective
- Analyze customer purchasing behavior.
- Segment customers into different groups using K-Means Clustering.
- Visualize customer clusters for better business insights.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## 📂 Dataset
- **File:** `Sample_Superstore.xls`
- The dataset contains customer transaction details, including Sales and Profit.

## 🚀 Features
- Load and process customer data.
- Apply K-Means clustering algorithm.
- Identify customer segments.
- Display cluster centers.
- Visualize customer groups using a scatter plot.

## 📊 Output
The project generates a scatter plot where:
- Different colors represent different customer clusters.
- Red **X** markers indicate the cluster centers (centroids).
- The visualization helps identify customer groups based on their purchasing patterns.
